# QuietCrypto Watcher

Private Telegram bot for personal crypto watchlists with one-time threshold and ongoing percent alerts, optional morning summaries, quiet hours, and owner analytics.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
